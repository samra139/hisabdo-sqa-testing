# HisabDo Website — SQA Testing Documentation

Department 3 – HisabDo Website Enhancement | SQA Team

## 📋 About
This repository contains the SQA (Software Quality Assurance) testing 
documentation for the HisabDo website, completed during Day 15–17 of 
the internship program.

## 📁 Files Included
- **Website_Audit_Report (2).docx** — Final audit report with all findings, 
  progress, and recommendations
- **Issues_For_MERN_Team.docx** — Consolidated list of issues requiring 
  code-level fixes, shared with the MERN development team
- **SQA_Test_Cases_Completed (1).xlsx** — Detailed test cases covering 
  devices, links, forms, SEO, and UI/UX, with results filled in
- **SQA_Testing_Tracker.xlsx** — Task tracker with status and findings
- **Website_Test_Plan.docx** — Test plan outlining scope and approach
